# LJT-Homepage

Personal homepage of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

- **About** (home page): academic background, research experience, skills, publications, honors, and contact information.
- **Publications**: publication list.

The included Jekyll workflow builds the site and deploys it to GitHub Pages. To publish, enable Pages once in the repository settings (Settings → Pages → Build and deployment → GitHub Actions), then run the "Deploy Academic Pages template site to Pages" workflow.
